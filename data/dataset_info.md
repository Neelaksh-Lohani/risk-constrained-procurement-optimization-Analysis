# Dataset Information

This project utilizes the **DataCo Smart Supply Chain Dataset** for procurement risk analysis.

Due to GitHub file size limitations, the dataset has not been uploaded to this repository.

---

## Dataset Source:

The dataset used in this project can be accessed from the following Kaggle link:

https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

---

## Dataset Description:

The dataset contains transactional procurement and logistics data across multiple sourcing regions, shipment modes, and product categories.

Each record represents a procurement transaction including:

- Order Date
- Shipment Date
- Shipment Mode
- Product Category
- Procurement Region
- Delivery Status
- Scheduled Shipment Time
- Actual Lead Time
- Procurement Cost
- Profit per Order

---

## Project Usage:

This dataset was used for:

- Supplier Delivery Performance Analysis
- Shipment Mode Reliability Benchmarking
- Lead Time Stability Assessment
- Procurement Cost Optimization
- SLA Compliance Monitoring
